# HTML & CSS Individual Assignment

This repository contains the completed individual tasks for the HTML/CSS coursework assignment at Astana IT University.

## Project Structure
- **index.html** (Task 1) - Personal webpage with profile card, lists, and navigation bar.
- **task2.html** (Task 2) - Simple layout structure using CSS `float` properties (without flexbox/grid).
- **task3.html** (Task 3) - Tribute page dedicated to actor Michael Mando, styled with Google Fonts and custom CSS.
- **task4.html** (Task 4) - Structured student grades table and a styled feedback form.
- **styles.css** - Global stylesheet containing styles for all pages.

## Technologies Used
- HTML5
- CSS3
- Visual Studio Code
